## Overview

This repository hosts the source code for my **professional public profile** — a minimal, privacy-respecting, and technically refined presence at **[mdasuaje.github.io](https://mdasuaje.github.io/)**.

It serves as a verifiable reference point for my professional identity, capabilities, and principles. No downloadable CVs, no direct contact data, no third-party tracking — only canonical links to verified professional channels.

## Design Principles

This profile adheres to four non-negotiable principles:

| Principle | Implementation |
|-----------|----------------|
| **Minimal Disclosure** | No CVs, photos, phones, direct emails, or operational docs published |
| **Verifiable Channels** | Only LinkedIn & GitHub as canonical identity & contact points |
| **Zero Third-Party Tracking** | No analytics, ad pixels, remote fonts, or third-party scripts |
| **Contextual Information** | Credentials & references shared only on legitimate professional need |

## Technical Stack

| Layer | Technology |
|-------|------------|
| **Hosting** | GitHub Pages (static, HTTPS enforced) |
| **Markup** | Semantic HTML5, valid JSON-LD `Person` schema |
| **Styling** | CSS Custom Properties, modular scale (1.25), 8px spacing system |
| **Typography** | Inter (UI) + JetBrains Mono (code) via Google Fonts (preconnect, non-blocking) |
| **Accessibility** | WCAG 2.1 AA — skip link, focus-visible, reduced-motion, ARIA labels |
| **Performance** | Single HTML file, no JS frameworks, no build step, <50KB gzipped |
| **SEO/Social** | OpenGraph, Twitter Cards, canonical URL, `robots` meta, sitemap-ready |
