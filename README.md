## Technical Stack

| Layer | Technology |
|-------|------------|
| **Hosting** | GitHub Pages (static, HTTPS enforced) |
| **Markup** | Semantic HTML5, valid JSON-LD `Person` schema |
| **Styling** | CSS Custom Properties, modular scale (1.25), 8px spacing system |
| **Typography** | Inter (UI) + JetBrains Mono (code) — **self-hosted WOFF2** (Zero-Trust) |
| **Accessibility** | WCAG 2.1 AA — skip link, focus-visible, reduced-motion, ARIA labels, `lang` attrs |
| **Performance** | Single HTML file, no JS frameworks, no build step, <50KB gzipped |
| **SEO/Social** | OpenGraph, Twitter Cards, canonical URL, `robots` meta, sitemap-ready |
